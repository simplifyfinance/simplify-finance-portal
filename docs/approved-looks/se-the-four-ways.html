Sample 3 — once you press Use this

The figures are locked. The borrowing capacity, the lending options and the compliance notes all read this one set and nothing else — so the number in a credit note and the number on this screen can never drift apart. Unlocking asks for a reason and is recorded.

Why locking matters. Without it, somebody re-ticks an add-back three weeks later and the compliance note still quotes the old figure — or the new one, and nobody knows which. Locked, the compliance note quotes a set of figures that has a name, a time and a person against it. If the documents change, you unlock, say why, and that is on the record too.
