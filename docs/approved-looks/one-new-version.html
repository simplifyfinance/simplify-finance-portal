How it knowsNo new moving parts

Every build already carries its own stamp. The page asks for the current stamp every few minutes, and again whenever you come back to the tab. A different stamp means a new version. It is one small request, not a connection held open.

It never reloads by itself. Somebody mid-sentence in a fact find would lose the sentence. It waits for the click, every time.

If the deal on screen has typing that has not saved yet, the words change to “Finish what you are typing, then reload” and the button waits for the save to land.

Not yet hides it for an hour, then it comes back — because a version left running for days eventually breaks in a way nobody can explain, which is the whole reason for building this.

What it is notSigning everyone out

Signing the team out would not fix this. A stale tab still runs its old code to draw the sign-in screen. It looks like a fix and is not one.
