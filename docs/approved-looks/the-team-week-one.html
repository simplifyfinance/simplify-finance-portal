The settlements team's first week

Four visual changes, from Belle and Ellesse's feedback of 22 November. Nothing else on these screens moves.

1 — A deal that is opening

"When I click on a deal, it doesn't open immediately. There's a bit delay before the deal loads." There is no loading screen anywhere in the portal, so the browser sits on the old page. This draws the moment the link is clicked, in the shape of the page that is coming. The screen is never blank.

2 — Where it is, named

"This one shows as Contracts Returned when I open the deal, but when I go back to the main pipeline, the status still shows as Formal." Both were right: the board names the step the deal has reached, the bar highlights the step it is waiting on. The heading now says the column, so the deal page and the board give the same answer. The beads are not touched.

3 — A reply under an attention note

"Can we also add an Edit option on the right side of each attention item? This would allow us to easily update or add progress notes directly under each attention." It is a Reply, not an Edit: the trail stays a trail, every entry dated and named, nothing typed over. The progress note lands indented under the thing it is about.
