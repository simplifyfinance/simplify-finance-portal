Self-employed income

Mock, 22 November 2026. Appears on the Income tab once somebody is marked self-employed. Invented client and company. Four screens, one after the other, as it would actually go.

1 — what you give it

One box, everything at once. It does not ask what each file is — every one of these documents names its entity, its ABN and its year, so the portal reads that off the document rather than asking somebody to classify a PDF. Large files go the same way the loan contracts now do, so a full set of financials is not a problem.

Drop the tax returns and financials here as many as you have · any size

Individual returns, company returns, financials and notices of assessment. Two years if you have them. The portal works out what each one is and which year it belongs to.

2 — what it worked out

Shown before a single figure is used. Anything it could not place sits at the top in red and waits for you — it never guesses an entity or a year, because a 2024 column read as 2025 is a number that then gets quoted to a lender.

3 — the figures, and what gets added back

The portal finds every candidate add-back and proposes it. It never decides. Depreciation is on by default because it almost always is. Interest is off, because it is only added back where the debt is being paid out. And the director’s wage is off with the reason showing — it is already counted as Dominic’s salary above, so adding it back here would count it twice. That one is the whole reason this is ticks and not arithmetic.

4 — the four ways to read those two years

All four, same size, nothing pre-chosen. You pick the figure you want to use, and then go and find the lender that allows it — which is the way round you actually work. The spread here is $56,000 of assessable income, which is the difference between a deal and no deal.
